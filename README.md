# Curso de Git - ASIR

## Descripción
Este repositorio contiene las prácticas y actividades realizadas durante el curso de Git del Grado Superior de Administración de Sistemas Informáticos en Red (ASIR).

## Requisitos
- Tener Git instalado.
- Disponer de una cuenta de GitHub.
- Tener acceso a una terminal de comandos.

## Instalación
1. Instalar Git desde la página oficial: https://git-scm.com/
2. Clonar el repositorio utilizando el comando:

   ```bash
   git clone URL_DEL_REPOSITORIO
   ```

## Ejecución
Para acceder a la carpeta del proyecto, ejecutar:

```bash
cd nombre-del-repositorio
```

Las prácticas se realizarán utilizando los comandos de Git desde la terminal y se subirán al repositorio de GitHub.
